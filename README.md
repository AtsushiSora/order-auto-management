# オーダーオート 管理システム

買取・販売・在庫・経費・入出金・車両別利益を1つにつなぐ社内管理システムです。

## 現在の実装範囲

- ログイン後TOP画面
- 在庫一覧・検索・状態絞込み
- 車両の仮登録
- 車両状態と書類確認状態の変更
- 車両経費・事業全体経費の登録
- 経費の修正と、確定経費から入出金への自動連携
- 予定費用と確定費用の区別
- 入金・支払い・一部処理・残額管理
- 入庫前の買取代金支払い禁止
- 車両別の暫定利益・予想利益・確定粗利計算
- 買取契約から入庫・支払い予定への連携
- 販売契約から売約・入金予定・納車への連携
- 古物台帳・経理の第2段階画面
- 古物台帳の自動生成・不足項目確認・印刷
- 車検証閲覧アプリのJSON／CSV取込みとQR読取り
- 元取引からの仕訳候補作成・確認・月別一般CSV出力
- 経費の領収書・請求書・計算書などの非公開証憑添付
- スマートフォンでの証憑撮影、PDF選択、1分間限定URLでの閲覧
- 証憑の完全削除は事業主だけに制限
- 販売契約からS（請求）・入金完了後のR（領収）を発行
- `S-年月-連番`／`R-年月-連番`の自動採番と発行履歴
- 電子・PDF／紙、内税表示、紙Rの印紙確認額、無効化履歴に対応
- 通常・スポットスタッフの紹介料、成果報酬、合意済み例外請求の精算管理
- 販売／買取・オークション／廃車ごとの固定額・手入力・粗利率計算
- 予定条件のスナップショット、1円未満切り捨て、確定後の入出金自動連携
- スタッフ精算の予定・確定・支払／回収済み・取消履歴
- 事業主によるスポットスタッフの担当案件割当
- スポットスタッフ本人による紹介案件の登録・修正
- 「紹介のみ／契約から全て担当」に応じた専用画面
- 全担当案件からの買取・販売契約入力と、在庫・入出金への連携
- 未割当の車両・契約、他スタッフの顧客・精算を非表示にするRLS
- テストモードでの事業主表示／スポット表示切替
- 販売サイト向け公開情報と問い合わせ管理
- パソコン・スマートフォン対応
- 共通Supabase用の初期データベース設計
- メールログイン・利用停止判定・30分無操作ログアウト
- 事業主・経理・通常スタッフ・スポットスタッフのRLS
- 事業主用の利用者一覧、権限変更、利用停止・復活
- 設定画面からの経理・通常・スポットスタッフ招待
- 利用者変更の監査履歴と、最後の事業主を停止できない安全制限
- 非公開Storageと操作履歴の土台
- スポット担当案件から販売・買取契約システムへの10分間限定の入力引き継ぎ
- 契約システムの完了を使い捨てトークンで受け取り、契約済み・在庫・入出金予定へ自動反映
- 事業主専用の契約連携履歴（連携待ち・反映済み・期限切れ・再発行による無効）
- 個人情報や内部エラーを残さない連携失敗分類と、事業主専用の安全な再試行

## 重要

Supabase接続情報を設定していない場合は初期デモ版です。表示データは架空で、追加・変更した内容は使用中のブラウザ内にだけ保存されます。

共通Supabaseは開発用プロジェクトへ接続済みです。本物のお客様情報、契約、署名、本人確認情報、入出金は、利用者別の権限とバックアップを本番運用前に最終確認するまで登録しないでください。

## 起動方法

```bash
npm install
npm run dev
```

パソコンで `http://localhost:5173/` を開きます。同じネットワーク内のスマートフォンやタブレットから確認するときは、開発画面に表示されるNetwork URLを使用します。

## 確認コマンド

```bash
npm run check
```

計算テスト、TypeScriptの型検査、本番用ビルドを順番に実行します。
